Troubleshooting

My browser cannot connect

  1. On the server computer open http://127.0.0.1:8130/healthz. If it opens, the server is fine.
  2. If not, the service is stopped. On Windows start e-approval-kr in services.msc; on Linux run sudo systemctl start e-approval-kr.
  3. If it opens on the server but not from other PCs, the server may be set to "this computer only". Switch to the office network in First setup, step 2 and restart the service.
  4. Still not working: check the firewall (below), that the server address (IP) is right, and that the PC is on the same office network.

"Port already in use"

Another program (or a second copy of this server) is using port 8130.

  • Check whether the server is already running and stop the duplicate.
  • Run on another port: e-approval-kr serve --port 8131. If you run it as a service, change the port in the service settings (location varies by version; see the installation notes).
  • Find who uses it: Windows netstat -ano | findstr 8130, Linux/macOS sudo lsof -i :8130.

Firewall

For other PCs to connect, the server's firewall must allow port 8130 from the office network only. Never open it to the whole internet.

  • Windows: if you ticked the LAN option during installation the rule already exists. To create it yourself (administrator PowerShell):
    New-NetFirewallRule -DisplayName e-approval-kr -Direction Inbound -Protocol TCP -LocalPort 8130 -RemoteAddress LocalSubnet -Action Allow
  • Linux (ufw): sudo ufw allow from 192.168.0.0/24 to any port 8130 proto tcp (adjust to your network)
  • macOS: check System Settings, Network, Firewall for incoming connections.

I forgot my password

Staff: ask your administrator to reissue a temporary password (Admin → Employees).

For administrators: the administrator's own password is lostReissue it with the CLI on the server (only an operator with access to the data folder can do this).
e-approval-kr -u admin emp resetpw admin
A new temporary password is printed once; you must change it at sign-in. On Linux and macOS service installs use the helper command: 
sudo e-approval-kr-admin -u admin emp resetpw admin

Where are the logs?

  • Linux: journalctl -u e-approval-kr -e
  • Windows: service logs are written to a log file in the install folder or the data folder (C:\ProgramData\e-approval-kr). The exact file name may differ by version; open the folder to check.
  • macOS: the folder /Library/Logs/e-approval-kr.
  • The history of who did what is under Admin → Audit log (감사로그) and in audit.log in the data folder.

Warnings during installation

  • Windows "protected your PC" window: More info → Run anyway. Steps
  • macOS "cannot be opened": right-click the file, Open; or Privacy & Security, Open Anyway. Steps

These appear because the program is not yet signed with a certificate. Make sure you downloaded it from the official release page before continuing.

Other

  • Sign-in is blocked: 5 wrong attempts for one ID (20 from the same PC address) within 10 minutes block sign-in for 10 minutes. Wait and retry, or ask an administrator to reissue the password.
  • An attachment will not upload: files must be at most 10 MB each, 30 MB in total, with an allowed extension.
  • The screen looks old: hard-refresh the browser with Ctrl+F5.

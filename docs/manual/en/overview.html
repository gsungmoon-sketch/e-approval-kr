1. Overview and terms

e-approval-kr (Python package gyeoljae, CLI command gyeol) is a Korean-style electronic approval (전자결재) web server. A small organization installs it on one office computer and staff draft and approve documents in a web browser. It uses only the Python standard library and behaves the same on Windows, macOS and Linux.

Main features

  • Employees, departments, positions, employee numbers, CSV bulk import, org chart
  • Draft, approval line, body, attachments, submit; approve, reject, withdraw, delegate, final approval, CC
  • Per-department approval rules (line template, amount-based final-approval limits, required CC, delegation rules), versioned
  • 10 built-in forms and an administrator form editor (tables, periods, required attachments)
  • Document boxes and search; internal mail, messages, board, file library; optional outgoing SMTP notifications
  • Hash-chained audit log with tamper check, optional two-person approval, daily automatic backup

Architecture

  직원 PC / staff PCs            서버 컴퓨터 / server computer
 +----------------+  HTTP(S)   +-------------------------------+
 | 웹 브라우저     | ---------> | e-approval-kr (port 8130)     |
 | web browser    |            |   web UI + CLI (same code)    |
 +----------------+            |   data folder:                |
   (설치 불필요)                |     gyeoljae.db  (SQLite)     |
   (nothing to install)        |     docs/ (본문·첨부 / bodies) |
                               |     audit.log, server.json    |
                               +-------------------------------+

The web UI and the CLI are two faces of the same functions. The CLI (supports --json) is an operator tool on the server computer, for automation and recovery. One computer is meant to handle tens to a few hundred users and a few thousand approvals per day (writes are processed one at a time).

Who can see what

A document can be seen by the drafter, (after submission) the approval line, delegates and CC recipients, and department-head-level staff of the drafting department (same-department staff too for completed documents if the drafter allows). Administrators cannot read other people's document bodies; they manage staff, rules and audit.

Terminology (Korean - English)

KoreanEnglishMeaning
결재approve / approvalReviewing and approving a document; the people on the approval line do it in turn.
기안draft (write a document)Writing a document, or the document itself. 기안자 = drafter.
상신submitPutting the finished draft onto its approval line. It cannot be edited afterwards.
반려rejectAn approver returns the document to the drafter with a reason (at least 5 characters).
회수withdrawThe drafter takes a submitted document back; only possible while nobody has approved yet.
대결delegate approval (approve on behalf)Someone designated approves in place of an absent approver; recorded as 대결 on the document.
전결final approval authorityIf the amount is within a position's limit, that position is the final approver and higher steps are skipped.
참조cc (copy)Designated read-only viewers; no approval right.
결재선approval lineThe ordered list of approvers a document passes through.
결재규정approval rules (policy)Per department and document type: approval line template, final-approval limits, required CC, delegation rules.
결재란approval boxThe stamp-box table at the top of a document: position, name, status, date.
양식(서식)form (template)The template of a draft: fields, approval type, retention period. Versioned.
문서번호document numberNumber issued at final approval (no gaps).
사번employee numberHire date YYMMDD + serial (e.g. 26111301). Default sign-in ID.
직위·서열position / rankJob title and its rank, used for approval lines, final approval and delegation.
부서장급department-head-levelA position marked department-head level; may read department documents and write notices.
2인 승인two-person approvalSafeguard that requires a second administrator to approve important admin changes.
감사로그audit logHash-chained record of every state change; tamper-checkable.
머리값audit headLatest sequence number and hash of the audit chain; stored elsewhere it also exposes a rewritten chain.
쪽지message (short note)Short internal message; approval notifications arrive as messages.
자료실file libraryCompany or department file sharing (same name = new version).
내 보관함my storagePrivate folders for collecting documents and files.

"참조" is cc. Do not confuse 대결 (someone approves in your place) with 전결 (final approval within a limit).

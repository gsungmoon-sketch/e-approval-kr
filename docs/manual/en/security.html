Security recommendations

Approval documents hold important company information. Please follow these points.

  1. Default is this computer only (127.0.0.1). Open it to the office network only when staff need to share it, and avoid exposing it directly to the internet (router port forwarding).
  2. Use an HTTPS proxy for LAN or outside access. Plain HTTP can be read on the same network. See HTTPS setup. Behind the proxy turn on GYEOLJAE_TRUST_PROXY=1 and GYEOLJAE_COOKIE_SECURE=1 (never without a proxy).
  3. Firewall: office network only. See Firewall.
  4. No demo data. Accounts from seed-demo use a publicly known password. Never use it with real data.
  5. Two or more administrators, and turn on two-person approval. See Two-person approval.
  6. Store backups elsewhere and encrypted. Backup zips contain document bodies and personal data. See Backup and restore.
  7. The SMTP password is stored in smtp.json in the data folder. Limit who can reach the data folder and backups to server administrators. Use a low-privilege account or app password.
  8. Data folder permissions. Only the service account and administrators should read it. Treat anyone with access to the data folder as able to do every administrative action through the CLI.
  9. Verify regularly. Run verify-audit monthly and store the export-audit-head value elsewhere. See audit head.
  10. Handle leavers at once. Setting someone to retired blocks sign-in and keeps records.
  11. Keep up to date. New versions may contain security fixes; see Upgrading.

Built-in protections

  • Sign-in attempt limits (5 per account and 20 per IP within 10 minutes).
  • Session cookies are HttpOnly and SameSite=Strict (Secure over HTTPS); every changing request is CSRF-checked.
  • Attachments: only allowed extensions and sizes; files are stored under numbers only.
  • Documents you may not see are answered as "does not exist".

If you find a vulnerability, please report it privately through GitHub Security Advisories instead of a public issue: https://github.com/gsungmoon-sketch/e-approval-kr/security/advisories/new

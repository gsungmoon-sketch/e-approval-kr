9. CLI reference

The help texts in this chapter are the actual output of gyeol <command> --help (version 0.2.1, checked on a server). Note that the help text itself is in Korean; an English summary of each command is given above its help. On installed packages use e-approval-kr instead of gyeol, and on Linux/macOS service installs use sudo e-approval-kr-admin.

Common usage

gyeol [--data DATA_DIR] [-u USER_ID] [--json] <command> ...
  • --data: data folder (default: environment variable GYEOLJAE_DATA, or the per-OS default).
  • -u: the acting user (also via GYEOLJAE_USER). It is not authentication; only operators of the server may use the CLI. Exception: change approve|reject re-confirm that administrator's password (terminal prompt; scripts use --password-file).
  • --json: machine-readable output. Amounts may be written like 150만 (1,500,000) or 1,500,000.
  • The commands used as examples (backup, restore, export-audit-head, check-audit-head, verify-audit, emp add/resetpw, dept add, policy edit/preview, draft/approve/reject/withdraw, delegate set, change approve, setting) were actually run against a temporary data folder.

Examples: common sequences

gyeol --data D backup 백업.zip                 # backup
gyeol --data D export-audit-head               # {"seq": 26, "hash": "..."}  -> store elsewhere
gyeol --data D check-audit-head 26 <hash>      # OK: 체인에 그대로 있음
gyeol restore 백업.zip --to 빈폴더              # restore (verifies the audit chain)
gyeol -u admin emp add --name 홍길동 --dept DEV --position 팀원 --hired 2026-11-13
gyeol -u admin emp resetpw 26111301            # new temporary password, shown once
gyeol -u dev1 draft --title "노트북 구매" --form expense --field purpose=업무용 --field pay=법인카드 \
      --row "items:item=노트북;qty=1;price=90만" --attach 영수증.pdf --submit
gyeol -u devlead approve 3 -m 확인 ; gyeol -u devlead reject 4 -m "사유를 다시 적어 주세요"
gyeol -u dev1 withdraw 4 ; gyeol -u devlead delegate set --to ceo --start 2026-11-14 --end 2026-11-20

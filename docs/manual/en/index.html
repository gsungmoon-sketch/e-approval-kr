e-approval-kr Manual

How to install, use and administer the e-approval-kr (결재) electronic approval server. If you are new, read chapters 1, 2, 3 in order; regular staff only need chapter 5.

Good to knowGreen For administrators boxes are for administrators who use commands (CLI). In file names, <version> stands for the real version number of the file you downloaded. Every chapter can be printed (saved as PDF).

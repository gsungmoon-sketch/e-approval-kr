Installation

Install the server on one computer. Staff then open it in a web browser on their own PCs; nothing needs to be installed on their machines.

Which one? Windows office PC: Windows / Mac: macOS / server machine: Linux / already have Python: pyz / containers: Docker

Download and verify

  1. From the official releases page github.com/gsungmoon-sketch/e-approval-kr/releases download the installer for the latest version together with the SHA256SUMS file.
  2. Compare the hash to be sure the file is not damaged or tampered with. The printed hash must equal the line for that file in SHA256SUMS. 
    # Linux
sha256sum -c --ignore-missing SHA256SUMS
# macOS
shasum -a 256 e-approval-kr-<version>-macos-arm64.pkg
# Windows (PowerShell)
Get-FileHash .\e-approval-kr-setup-<version>-win-x64.exe -Algorithm SHA256
  3. If they differ, do not install; download again.
Unsigned installersThe installers are not yet code-signed (Windows) or notarized (macOS), so the operating system shows a warning. The hash check above is how you confirm the file is genuine. File names look like e-approval-kr-<version>-<os>-<x64|arm64>.
Status of the installersInstall paths (folders, service names) in this manual follow the packaging plan. If the notes of an actual release differ, the release notes win.

Windows

File: e-approval-kr-setup-<version>-win-x64.exe (64-bit Windows)

  1. Double-click the downloaded file.
  2. A blue "Windows protected your PC" window may appear. This happens because the installer is not code-signed yet. Click More info, then click the Run anyway button that appears (on a Korean Windows: 추가 정보 → 실행).
  3. If asked to allow changes to your device, click Yes (administrator rights are needed).
  4. Click Next through the wizard. The program goes to C:\Program Files\e-approval-kr; your data (documents, attachments, staff records) goes to C:\ProgramData\e-approval-kr.
  5. If you see an option to allow access from the office network (a firewall rule), tick it only if other PCs must connect. Leave it unticked if only this PC will use the server.
  6. Click Install, then Finish. The server is registered as a Windows service and starts automatically when the PC starts.
  7. Your browser opens http://127.0.0.1:8130/setup. Continue with First setup.

Three Start menu shortcuts are added:

NameWhat it does
서버 열기 (Open server)Opens the approval screen in your browser.
관리 도구 (Admin tools)Opens a command window for the administrator CLI.
설명서 (Manual)Opens this manual.

Uninstall: Settings, Apps, e-approval-kr, Uninstall. Your data is kept. To remove the data as well, tick 데이터도 삭제 ("also delete data") during uninstall. That cannot be undone, so back up first.

macOS

File: a .pkg. Use arm64 for Apple silicon Macs (M1 and later) and x86_64 for Intel Macs (check under Apple menu, About This Mac).

  1. Double-click the .pkg. Because it is not signed, macOS says it cannot be opened.
  2. Option 1 (macOS 14 and earlier): right-click (or Control-click) the file, choose Open, then click Open in the dialog. The warning says "unidentified developer" (확인되지 않은 개발자).
  3. Option 2 (all versions; the only way on macOS 15 Sequoia and later): first try to open the .pkg once so the block message appears, then open System Settings, Privacy & Security, and in the "Security" section click Open Anyway. You are asked for your login password.
  4. Click Continue and Install, and enter your Mac login password.
  5. The program is installed in /usr/local/lib/e-approval-kr and the server (LaunchDaemon com.e-approval-kr.server) starts automatically. Data is stored in /Library/Application Support/e-approval-kr.
  6. Open http://127.0.0.1:8130/setup in a browser and continue with First setup.
For administratorsStop / start the server:
sudo launchctl unload /Library/LaunchDaemons/com.e-approval-kr.server.plist
sudo launchctl load -w /Library/LaunchDaemons/com.e-approval-kr.server.plist
Logs are in /Library/Logs/e-approval-kr. For administration use sudo e-approval-kr-admin ... (runs as the service account _eapprovalkr). Uninstall with sudo /usr/local/lib/e-approval-kr/uninstall.sh.

Linux

File: e-approval-kr-<version>-linux-x64.tar.gz

For administrators
tar xzf e-approval-kr-<version>-linux-x64.tar.gz
cd e-approval-kr-<version>-linux-x64
sudo ./install.sh          # reachable from this machine only (default)
sudo ./install.sh --lan    # reachable from the office network (0.0.0.0)
  • A system user e-approval-kr is created.
  • Program: /opt/e-approval-kr / data: /var/lib/e-approval-kr / service: e-approval-kr.service (systemd, starts at boot).
  • Status: systemctl status e-approval-kr / logs: journalctl -u e-approval-kr -e
  • Afterwards open http://127.0.0.1:8130/setup in a browser. If the server has no screen, see "Setting up when the server has no screen" in First setup.
  • For administration (CLI) use sudo e-approval-kr-admin ... (runs as the service account). To create the first administrator without a screen: sudo e-approval-kr-admin setup. Options: --port N, --no-start. --lan opens the port in ufw (if active) only for private subnets (10.x, 172.16-31.x, 192.168.x).
  • Works on x86_64 Linux with glibc 2.35 or newer; Python is not needed. Running install.sh again from a newer tarball upgrades and keeps the data.

Python 3.10 or newer (pyz file)

If Python 3.10+ is already installed, one file is enough. No service is registered, so this suits trials and very small offices.

For administrators
python3 e-approval-kr-<version>.pyz serve
# Windows: py e-approval-kr-<version>.pyz serve
python3 e-approval-kr-<version>.pyz setup      # create the first admin in the terminal

Choose the data folder with the GYEOLJAE_DATA environment variable or --data FOLDER. Otherwise a per-user folder is used (Windows %LOCALAPPDATA%\gyeoljae, macOS ~/Library/Application Support/gyeoljae, Linux ~/.local/share/gyeoljae). Closing the terminal window stops the server.

Docker

For administratorsBuild an image from the repository's Dockerfile and run it:
docker build -t e-approval-kr .
docker run --rm -it -v e-approval-data:/data e-approval-kr setup      # first administrator (terminal)
docker run -d --name e-approval-kr -p 127.0.0.1:8130:8130 -v e-approval-data:/data e-approval-kr
To use the browser wizard with Docker, open the one-time /setup?key=… address printed in the container log (docker logs e-approval-kr). Connections from outside the container need this key; to choose it yourself pass -e GYEOLJAE_SETUP_TOKEN=<16+ chars>. You can also create the administrator with the setup command first, as above.
  • Data lives in the volume mounted at /data. Deleting the volume deletes the data.
  • The server listens on 0.0.0.0:8130 inside the container; -p 127.0.0.1:8130:8130 makes it reachable from this computer only. To open it to the LAN use -p 8130:8130 (an HTTPS proxy is recommended, see HTTPS). More in docs/DEPLOY.md.

Check that it works

  1. Open http://127.0.0.1:8130/healthz in a browser. A short OK response means the server is running.
  2. If not, see Troubleshooting.

문제 해결

브라우저에 접속이 안 돼요

  1. 서버 컴퓨터에서 http://127.0.0.1:8130/healthz를 열어 보세요. 열리면 서버는 정상입니다.
  2. 안 열리면 서비스가 꺼져 있는 것입니다. Windows는 services.msc에서 e-approval-kr을 시작, Linux는 sudo systemctl start e-approval-kr.
  3. 서버에서는 열리는데 다른 PC에서 안 열리면, 접속 범위가 "이 컴퓨터만"일 수 있습니다. 첫 설정 2단계에서 사내망으로 바꾸고 서비스를 다시 시작하세요.
  4. 그래도 안 되면 방화벽(아래)과 서버 주소(IP)가 맞는지 확인합니다. 같은 사무실 네트워크에 있는 PC인지도 확인하세요.

"포트가 이미 사용 중" 오류

8130 포트를 다른 프로그램(또는 같은 서버를 두 번 실행한 것)이 쓰고 있습니다.

  • 서버가 이미 실행 중인지 확인하고 중복 실행을 끕니다.
  • 다른 포트로 실행: e-approval-kr serve --port 8131. 서비스로 쓰고 있다면 서비스 설정에서 포트를 바꿉니다(버전별 설정 위치는 설치 안내를 참고).
  • 누가 쓰는지 확인: Windows netstat -ano | findstr 8130, Linux/macOS sudo lsof -i :8130.

방화벽

다른 PC에서 접속하게 하려면 서버의 방화벽이 8130 포트를 사내망에서만 허용해야 합니다. 인터넷 전체에 열지 마세요.

  • Windows: 설치 때 "사내망 접속 허용"을 체크했다면 이미 만들어져 있습니다. 직접 만들려면(관리자 PowerShell):
    New-NetFirewallRule -DisplayName e-approval-kr -Direction Inbound -Protocol TCP -LocalPort 8130 -RemoteAddress LocalSubnet -Action Allow
  • Linux(ufw): sudo ufw allow from 192.168.0.0/24 to any port 8130 proto tcp (사내 대역에 맞게 바꾸세요)
  • macOS: 시스템 설정 → 네트워크 → 방화벽에서 들어오는 연결 허용 여부를 확인합니다.

비밀번호를 잊었어요

일반 직원: 관리자에게 임시 비밀번호 재발급을 요청합니다(관리 → 사원).

관리자용: 관리자 본인 비밀번호 분실서버 컴퓨터에서 CLI로 재발급합니다(데이터 폴더에 접근할 수 있는 운영자만 가능).
e-approval-kr -u admin emp resetpw admin
새 임시 비밀번호가 한 번 출력됩니다. 로그인하면 바로 바꾸게 됩니다. Linux·macOS 서비스 설치본에서는 도우미 명령을 쓰세요. 
sudo e-approval-kr-admin -u admin emp resetpw admin

로그는 어디에 있나요?

  • Linux: journalctl -u e-approval-kr -e
  • Windows: 서비스 로그는 설치 폴더 또는 데이터 폴더(C:\ProgramData\e-approval-kr) 안의 로그 파일에 남습니다. 정확한 파일 이름은 버전별로 다를 수 있으니 폴더를 열어 확인하세요.
  • macOS: /Library/Logs/e-approval-kr 폴더.
  • 업무 이력(누가 무엇을 했는지)은 관리 → 감사로그와 데이터 폴더의 audit.log에 있습니다.

설치 때 경고가 나와요

  • Windows "PC 보호" 창: 추가 정보 → 실행. 설명
  • macOS "열 수 없음": 파일 오른쪽 클릭 → 열기, 또는 개인정보 보호 및 보안 → "그래도 열기". 설명

이 프로그램은 아직 인증서로 서명되지 않아서 나오는 경고입니다. 받은 곳이 공식 배포 페이지인지 꼭 확인한 뒤 진행하세요.

그 밖에

  • 로그인이 막혔어요: 같은 아이디로 10분에 5번(같은 PC 주소에서는 20번) 틀리면 10분 동안 막힙니다. 기다렸다 다시 시도하거나, 관리자가 비밀번호를 재발급하세요.
  • 첨부가 올라가지 않아요: 파일 하나 10MB, 합계 30MB 이하이고 허용된 확장자인지 확인하세요.
  • 화면이 옛날 그대로예요: 브라우저에서 Ctrl+F5로 새로 고칩니다.

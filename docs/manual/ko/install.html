설치

서버로 쓸 컴퓨터 한 대에 설치합니다. 직원들은 자기 컴퓨터의 웹 브라우저로 접속합니다. 직원 PC에는 아무것도 설치하지 않습니다.

어떤 방법을 고를까요? Windows 사무용 PC → Windows / Mac → macOS / 서버 컴퓨터 → Linux / Python을 이미 쓰는 분 → pyz / 컨테이너 사용자 → Docker

내려받기와 확인

  1. 공식 배포 페이지 github.com/gsungmoon-sketch/e-approval-kr/releases에서 최신 버전의 설치 파일과 SHA256SUMS 파일을 함께 받습니다.
  2. 받은 파일이 손상·변조되지 않았는지 해시를 비교합니다. 출력된 해시가 SHA256SUMS의 같은 파일 줄과 같아야 합니다. 
    # Linux
sha256sum -c --ignore-missing SHA256SUMS
# macOS
shasum -a 256 e-approval-kr-<버전>-macos-arm64.pkg
# Windows (PowerShell)
Get-FileHash .\e-approval-kr-setup-<버전>-win-x64.exe -Algorithm SHA256
  3. 다르면 설치하지 말고 다시 받으세요.
서명되지 않은 설치 파일설치 파일은 아직 코드 서명(Windows)·공증(macOS)이 되어 있지 않아 운영체제가 경고를 보여 줍니다. 위의 해시 확인이 그 대신 파일이 진짜임을 확인하는 방법입니다. 설치 파일 이름은 e-approval-kr-<버전>-<os>-<x64|arm64> 형식입니다.
설치 파일 준비 상태이 설명서의 설치 경로(폴더·서비스 이름)는 배포 계획에 따른 것입니다. 실제 릴리스의 안내(README)와 다르면 릴리스 쪽이 우선합니다.

Windows

받을 파일: e-approval-kr-setup-<버전>-win-x64.exe (64비트 Windows)

  1. 받은 파일을 두 번 클릭합니다.
  2. "Windows의 PC 보호" 파란 창이 뜰 수 있습니다. 이 프로그램은 아직 서명(인증)되지 않은 무료 프로그램이라서 나오는 경고입니다. 추가 정보를 누르고, 나타나는 실행 버튼을 누릅니다.
  3. "이 앱이 디바이스를 변경하도록 허용" 창이 뜨면 예를 누릅니다(관리자 권한 필요).
  4. 설치 마법사에서 다음을 눌러 진행합니다. 프로그램은 C:\Program Files\e-approval-kr에, 데이터(문서·첨부·사원 정보)는 C:\ProgramData\e-approval-kr에 저장됩니다.
  5. "사내망(LAN)에서 접속 허용" 항목(방화벽 규칙)이 나오면, 다른 직원 PC에서도 접속하게 하려는 경우에만 체크합니다. 이 PC에서만 쓸 거라면 체크하지 마세요.
  6. 설치를 누르고 끝나면 마침을 누릅니다. 서버는 Windows 서비스로 등록되어 PC를 켜면 자동으로 시작됩니다.
  7. 브라우저가 열리고 http://127.0.0.1:8130/setup 화면이 나옵니다. 이어서 첫 설정을 진행하세요.

시작 메뉴에 세 가지 바로가기가 생깁니다.

이름하는 일
서버 열기브라우저로 결재 화면을 엽니다.
관리 도구명령 창(관리자용 CLI)을 엽니다.
설명서이 설명서를 엽니다.

삭제: 설정 → 앱 → e-approval-kr → 제거. 삭제해도 데이터는 남습니다. 데이터까지 지우려면 삭제 중 나오는 데이터도 삭제에 체크하세요. 체크하면 되돌릴 수 없으니 먼저 백업하세요.

macOS

받을 파일: .pkg 파일. Apple 실리콘(M1 이후) Mac은 arm64, Intel Mac은 x86_64용을 받습니다. (애플 메뉴 → 이 Mac에 관하여 에서 칩을 확인)

  1. 받은 .pkg를 두 번 클릭합니다. 서명되지 않은 프로그램이라 "열 수 없습니다" 안내가 나옵니다.
  2. 방법 1(macOS 14 이하): 파일을 오른쪽 클릭(또는 Control+클릭) → 열기를 고르고, 다시 나오는 창에서 열기를 누릅니다. 안내 문구는 "확인되지 않은 개발자"로 나옵니다.
  3. 방법 2(모든 버전, macOS 15 Sequoia 이상은 이 방법만 가능): 먼저 .pkg를 한 번 열어 차단 안내를 띄운 다음 시스템 설정 → 개인정보 보호 및 보안을 열고 아래쪽 "보안" 항목의 그래도 열기(Open Anyway)를 누릅니다. 로그인 암호를 묻습니다.
  4. 설치 마법사의 계속, 설치를 누르고, Mac 로그인 암호를 입력합니다.
  5. 프로그램은 /usr/local/lib/e-approval-kr에 설치되고 서버(LaunchDaemon com.e-approval-kr.server)가 자동으로 시작됩니다. 데이터는 /Library/Application Support/e-approval-kr에 저장됩니다.
  6. 브라우저에서 http://127.0.0.1:8130/setup을 열고 첫 설정을 진행합니다.
관리자용서버 끄기/켜기:
sudo launchctl unload /Library/LaunchDaemons/com.e-approval-kr.server.plist
sudo launchctl load -w /Library/LaunchDaemons/com.e-approval-kr.server.plist
로그는 /Library/Logs/e-approval-kr. 관리 명령은 sudo e-approval-kr-admin ...(서비스 계정 _eapprovalkr로 실행). 삭제는 sudo /usr/local/lib/e-approval-kr/uninstall.sh.

Linux

받을 파일: e-approval-kr-<버전>-linux-x64.tar.gz

관리자용
tar xzf e-approval-kr-<버전>-linux-x64.tar.gz
cd e-approval-kr-<버전>-linux-x64
sudo ./install.sh          # 이 서버 안에서만 접속(기본)
sudo ./install.sh --lan    # 사내망에서 접속 허용(0.0.0.0)
  • 시스템 사용자 e-approval-kr이 만들어집니다.
  • 프로그램: /opt/e-approval-kr · 데이터: /var/lib/e-approval-kr · 서비스: e-approval-kr.service(systemd, 부팅 시 자동 시작)
  • 관리 명령(CLI)은 sudo e-approval-kr-admin ...(서비스 계정으로 실행됨). 첫 관리자를 화면 없이 만들려면 sudo e-approval-kr-admin setup. 옵션: --port N, --no-start. --lan은 ufw가 켜져 있으면 사설 대역(10.x·172.16~31.x·192.168.x)에서만 포트를 엽니다.
  • x86_64·glibc 2.35 이상 Linux에서 동작하며 Python은 필요 없습니다. 같은 폴더에서 install.sh를 다시 실행하면 데이터를 유지한 채 업그레이드됩니다.
  • 관리 명령(CLI)은 sudo e-approval-kr-admin ...(서비스 계정으로 실행됨). 첫 관리자를 화면 없이 만들려면 sudo e-approval-kr-admin setup. 옵션: --port N, --no-start. --lan은 ufw가 켜져 있으면 사설 대역(10.x·172.16~31.x·192.168.x)에서만 포트를 엽니다.

  • 관리 명령(CLI)은 sudo e-approval-kr-admin ...(서비스 계정으로 실행됨). 첫 관리자를 화면 없이 만들려면 sudo e-approval-kr-admin setup. 옵션: --port N, --no-start. --lan은 ufw가 켜져 있으면 사설 대역(10.x·172.16~31.x·192.168.x)에서만 포트를 엽니다.

  • 상태 확인: systemctl status e-approval-kr · 로그: journalctl -u e-approval-kr -e
  • 설치 후 브라우저에서 http://127.0.0.1:8130/setup을 엽니다. 서버에 화면이 없다면 첫 설정의 "다른 PC에서 설정하기"를 보세요.
  • 삭제: sudo ./uninstall.sh (데이터 유지) / sudo ./uninstall.sh --purge (데이터까지 삭제, 되돌릴 수 없음)

Python 3.10 이상 (pyz 파일)

Python 3.10 이상이 이미 설치되어 있다면 파일 하나로 실행할 수 있습니다. 서비스 등록은 되지 않으므로 시험·소규모용으로 알맞습니다.

관리자용
python3 e-approval-kr-<버전>.pyz serve
# Windows: py e-approval-kr-<버전>.pyz serve
python3 e-approval-kr-<버전>.pyz setup      # 첫 관리자 만들기(터미널)

데이터는 환경변수 GYEOLJAE_DATA 또는 --data 폴더로 정합니다. 정하지 않으면 사용자 폴더(Windows %LOCALAPPDATA%\gyeoljae, macOS ~/Library/Application Support/gyeoljae, Linux ~/.local/share/gyeoljae)를 씁니다. 터미널 창을 닫으면 서버도 꺼집니다.

Docker

관리자용저장소의 Dockerfile로 이미지를 만든 뒤 실행합니다.
docker build -t e-approval-kr .
docker run --rm -it -v e-approval-data:/data e-approval-kr setup      # 첫 관리자(터미널)
docker run -d --name e-approval-kr -p 127.0.0.1:8130:8130 -v e-approval-data:/data e-approval-kr
Docker에서 브라우저 마법사를 쓰려면 컨테이너 로그(docker logs e-approval-kr)에 찍힌 /setup?key=… 1회용 주소를 여세요(컨테이너 밖 접속은 이 열쇠가 있어야만 열림, 열쇠를 정하려면 -e GYEOLJAE_SETUP_TOKEN=16자이상). 위처럼 setup 명령으로 먼저 관리자를 만들어도 됩니다.
  • 데이터는 볼륨 /data에 저장됩니다. 볼륨을 지우면 데이터도 사라지니 주의하세요.
  • 외부 공개는 앞에 HTTPS 프록시를 두세요(HTTPS).
  • 이미지는 컨테이너 안에서 0.0.0.0:8130으로 실행되고, -p 127.0.0.1:8130:8130 덕분에 이 컴퓨터에서만 접속됩니다. LAN에 열려면 -p 8130:8130(HTTPS 프록시 권장). 자세한 내용은 docs/DEPLOY.md.

설치가 잘 됐는지 확인

  1. 브라우저에서 http://127.0.0.1:8130/healthz를 엽니다. 간단한 정상 응답이 나오면 서버가 켜진 것입니다.
  2. 문제가 있으면 문제 해결을 보세요.

첫 설정 마법사

설치가 끝나면 브라우저에 http://127.0.0.1:8130/setup 화면이 열립니다. 자동으로 열리지 않으면 주소창에 직접 입력하세요. 설정은 서버가 설치된 바로 그 컴퓨터에서만 할 수 있습니다(다른 PC에서는 막혀 있습니다. 안전을 위한 것입니다).

1단계. 첫 관리자 만들기

  1. 아이디(예: admin), 이름(예: 관리자), 비밀번호를 입력합니다.
  2. 비밀번호는 길고 추측하기 어렵게 정하고, 안전한 곳에 적어 두세요. 분실하면 CLI로 재발급해야 합니다.

2단계. 접속 범위(바인드 주소)

선택뜻언제
이 컴퓨터만 (127.0.0.1)이 컴퓨터의 브라우저에서만 접속됩니다.혼자 쓰거나 시험할 때. 기본값이며 가장 안전합니다.
사내망(LAN) (0.0.0.0)같은 사무실 네트워크의 다른 PC에서도 접속됩니다.직원이 함께 쓸 때.
주의사내망을 고르면 마법사가 경고를 보여 줍니다. 암호화되지 않은 HTTP로는 같은 네트워크의 다른 사람이 내용을 엿볼 수 있으므로, HTTPS 프록시를 앞에 두는 것을 권장합니다. 인터넷에 직접 여는 것(공유기 포트포워딩)은 권장하지 않습니다.

접속 범위를 바꾼 뒤에는 서비스를 다시 시작해야 적용됩니다.

  • Windows: 서비스 관리(Win+R → services.msc)에서 e-approval-kr을 찾아 오른쪽 클릭 → 다시 시작
  • macOS: 시스템을 다시 시작하거나 설치 페이지의 launchctl 명령 사용
  • Linux: sudo systemctl restart e-approval-kr

3단계. 백업 폴더 정하기

백업을 저장할 폴더를 고릅니다. 하루에 한 번 자동으로 백업이 만들어지고 최근 14개를 보관합니다(오래된 것은 자동 삭제). 첫 백업은 설정을 마치는 즉시 만들어집니다(폴더에 쓸 수 없으면 오류로 알려 줌). 가능하면 서버와 다른 디스크(외장 디스크, 네트워크 저장소)의 폴더를 고르세요. 서버 디스크가 고장 나면 같은 디스크의 백업도 함께 사라집니다. 자세한 내용은 백업·복구를 보세요.

마법사 입력칸과 저장되는 곳

칸설명
관리자 아이디·이름·비밀번호비밀번호는 8자 이상, 두 번 입력해 확인합니다.
관리 부서 코드·이름첫 관리자가 속할 부서(기본 ADM·관리부). 나중에 바꿀 수 있습니다.
접속 범위·포트이 컴퓨터만(127.0.0.1) / 사내망(0.0.0.0), 기본 포트 8130.
백업 폴더비우면 자동 백업을 하지 않습니다.
  • 접속 범위·포트·백업 폴더는 데이터 폴더의 server.json(host, port, backup_dir, backup_keep)에 저장됩니다. serve를 옵션 없이 실행하면 이 파일을 읽습니다. serve --host … --port …로 직접 주면 그쪽이 우선합니다.
  • 설정이 끝나면 /setup 주소는 로그인 화면으로 바뀝니다(사용자가 생긴 뒤에는 다시 열리지 않음). 마법사 중에는 http://127.0.0.1:8130/healthz가 {"ok": true, "version": "…"}를 돌려줍니다(서비스 감시용).
  • Linux에서 설치 때 --lan 또는 --port를 썼다면 서비스 설정의 listen.conf가 server.json보다 우선합니다. 다시 server.json을 쓰려면 /etc/systemd/system/e-approval-kr.service.d/listen.conf를 지우고 sudo systemctl daemon-reload && sudo systemctl restart e-approval-kr.
  • 다른 PC에서 /setup을 열면 "서버가 설치된 컴퓨터에서 여세요"라는 안내만 보입니다.

4단계. 끝내고 로그인

마법사를 마치면 로그인 화면으로 갑니다. 방금 만든 관리자 아이디로 로그인하고, 다음 순서로 조직을 준비합니다.

  1. 관리 → 부서 등록
  2. 관리 → 직위·서열 확인(기본 직위가 있으며 고칠 수 있음)
  3. 관리 → 사원 등록(또는 CSV 일괄 등록)
  4. 관리 → 규정·전결에서 부서별 결재선 설정

자세한 방법은 관리자 설명서에 있습니다.

관리자용: 마법사 없이 설정 
echo '여기에비밀번호' > pw.txt
e-approval-kr setup --admin-id admin --admin-name 관리자 --password-file pw.txt
# 비밀번호 파일은 쓰고 나면 바로 삭제하세요
e-approval-kr serve --host 127.0.0.1 --port 8130

다른 PC에서 접속하게 하려면 --host 0.0.0.0. 서비스 설치본에서는 서비스 설정에 주소가 들어 있으므로 마법사(또는 설정 파일)로 바꾸고 서비스를 다시 시작합니다. 서버 상태 확인: GET /healthz.

다른 PC에서 설정이 필요할 때: 서버에 SSH나 원격 데스크톱으로 접속한 뒤 그 안의 브라우저에서 127.0.0.1:8130/setup을 열거나, 위 CLI 방법을 쓰세요.

HTTPS로 안전하게 공개하기

사내망이나 외부(재택·모바일)에서 접속하게 할 때는 앞에 HTTPS 리버스 프록시를 둡니다. 프록시가 암호화를 맡고, e-approval-kr은 계속 127.0.0.1:8130에서 실행합니다.

관리자용: Caddy 예
  1. 도메인(예: approval.example.com)이 서버를 가리키게 하고, 80·443 포트를 엽니다.
  2. 서버 환경변수에 GYEOLJAE_TRUST_PROXY=1, GYEOLJAE_COOKIE_SECURE=1을 줍니다. 프록시 뒤에서만 켜세요(직접 노출된 서버에서 켜면 로그인 제한을 속일 수 있습니다).
  3. Caddyfile:
    approval.example.com {
    reverse_proxy 127.0.0.1:8130
}
    저장소의 deploy/caddy/Caddyfile 예시도 참고하세요. 인증서는 Caddy가 자동으로 받습니다.

다른 방법: Cloudflare Tunnel(포트포워딩 불필요), 또는 서버 자체 HTTPS(serve --https 인증서.pem 키.pem). 자세한 내용은 저장소 docs/DEPLOY.md.

# 결재 UI 레이아웃 명세 (ui-layout)

서버 렌더링 HTML, JS 없이 동작, 한국어, 데스크톱+휴대폰. 기존 `docs/ui-home.md`(홈 시나리오)를 보완하는 전체 화면 규격.
정적 목업: `docs/mock/home.html`, `docs/mock/doc-view.html` (외부 CDN 없음, 브라우저로 직접 열기).

## 0. 조사 요약 (일반 패턴만, 특정 브랜드 외형 차용 없음)
국내 그룹웨어/전자결재(다우오피스·네이버웍스·하이웍스·아마란스 류)와 MS/Google 승인 흐름의 공통점을 일반화했다.
| 영역 | 공통 패턴 | 본 앱 채택 |
|---|---|---|
| 홈 | 상단 공지/요약 카운터 → 결재대기·진행 위젯 → 메일/쪽지/게시판 최신글 → 일정/근태 | 카운터 띠 → 결재대기·진행 2열 → 완료/반려 → 쪽지·공지 (일정·근태는 범위 밖) |
| 좌측 메뉴 | 결재: 결재대기·진행·완료·반려·참조/열람·기안함·임시저장·부서문서함, 각 항목에 건수 배지, 접이식 트리 | 동일, 1단 트리(접이식은 `<details>`, JS 불필요) |
| 기안 | ① 양식 선택 → ② 결재선 지정 패널(조직도 검색, 순서 변경, 합의/참조/전결) → ③ 제목·본문 → ④ 첨부 → 상신/임시저장 | 한 화면 세로 4단계 번호 카드. 결재선은 우측(데스크톱)/상단 카드(폰) |
| 문서 보기 | 우상단 결재란(직위/이름/일자 도장칸 표), 문서번호·보존기간 머리 표, 하단 의견/이력, 결재·반려 버튼은 상단 고정 바 | 동일. 버튼은 상단 바 + 폰은 하단 고정 바 |
| 목록 | 문서번호·제목·기안자·기안일·상태·현재결재자, 상태 필터 탭, 검색, 페이지 번호 | 동일, 폰은 카드형 2줄 |
| 기타 | 메일/쪽지/게시판/자료실/조직도는 상단 앱 전환 또는 좌측 대메뉴 그룹 | 좌측 그룹 "소통" 아래 배치, 폰은 "더보기" |

## 1. 시나리오 (먼저)
### 1.1 팀원 — 기안 → 결과 확인
1. 홈에서 [기안하기] 클릭 → "양식 선택"(일반/지출/휴가) 카드. 예측: 선택하면 같은 쪽에서 작성폼 표시.
2. 작성: 제목(필수)·본문·첨부, **결재선 패널**에서 이름/부서 검색 → [추가] → ▲▼로 순서, 합의/참조 구분. 기본 결재선은 규정에 따라 자동 채움(수정 가능 범위 표시).
3. [상신] → 확인 화면: 결재선·제목 요약 + "상신하면 내용을 고칠 수 없고 회수만 가능" 안내 → [상신 확정]. 완료 후 문서 보기로 이동, 상단 녹색 알림 "상신됨(문서번호 …)".
4. 안전: 작성 중 다른 메뉴 클릭 시 폼 안에 "저장하지 않은 내용은 사라집니다. [임시저장]" 문구를 상시 표시(JS 없는 환경은 `beforeunload` 불가 → 항상 보이는 [임시저장] 버튼 + 마지막 저장 시각). JS 가능 시 `beforeunload` 경고 추가(향상 기능).
5. 반려되면 홈 '반려' 위젯과 쪽지 알림 → 문서 보기에서 사유 확인 → [수정 후 재기안].
### 1.2 부서장 — 결재
1. 홈 '결재대기 N'(오래된 순, 3일 초과는 "지연" 칩). 클릭 → 문서 보기.
2. 문서 확인(결재란에서 내 차례 칸 강조) → 의견(선택) 입력 → [결재].
3. **실수 결재 방지**: [결재] → 확인 화면(문서번호·제목·"결재하면 취소할 수 없습니다" ·비밀번호 재입력 요구 시 입력란) → [결재 확정]. 확인 화면의 기본 포커스는 [취소].
4. [반려] → 사유 입력 화면(필수, 5자 이상, 비면 인라인 오류 + 입력값 유지) → [반려 확정].
5. 완료 후 다음 결재대기 문서로 가는 링크 "다음 문서(2건 남음)".
### 1.3 관리자
관리 메뉴: 사원·부서·직위·규정(전결 한도)·결재선 기본값·양식·감사로그·백업. 위험 작업(삭제·서열 변경·계정 정지)은 확인 화면 + 사유 + 2인 승인 표시. 목록은 표, 변경은 별도 상세 화면(한 화면에 한 작업).
### 1.4 예외
- 문서 없음: 빈 상태 카드 "결재 대기 문서가 없습니다" + 다음 행동 링크(기안하기).
- 100건 이상: 20건/페이지, 하단 `« 이전 1 2 3 … 다음 »` + "총 N건", 필터는 쿼리스트링 유지.
- 긴 제목: 목록은 1줄 말줄임(`text-overflow`) + `title` 속성; 폰 카드는 2줄까지; 문서 보기는 줄바꿈 전체 표시(`overflow-wrap:anywhere`).
- 세션 만료: 제출 시 로그인 화면으로 이동하며 `next` 유지, 작성 중이던 본문은 만료 전 임시저장본으로 복구 안내. 만료 5분 전 폼 상단 안내(향상 기능).
- 좁은 폰(360px): 좌측 메뉴 숨김→하단 탭, 표→카드, 결재란은 가로 스크롤 없이 칸 폭 축소(최대 6칸, 넘으면 2줄).
- 권한 없음: 403 화면에 사유와 홈 링크. 이미 처리된 문서에 재결재 시도: "이미 처리된 문서" 안내.

## 2. 레이아웃 그리드
```
┌──────────────────────────────────────────────────────────────┐
│ HEADER 56px: ☰(폰) 로고·앱명 │ 통합검색 │ 쪽지N · 알림 · 이름▾ │
├────────────┬─────────────────────────────────┬───────────────┤
│ LEFT NAV   │ CONTENT (max 1100px)            │ RIGHT PANEL   │
│ 220px      │ 제목줄 + 액션 / 본문             │ 280px (선택)   │
│ 고정       │                                 │ 결재선·요약·   │
│            │                                 │ 도움말         │
└────────────┴─────────────────────────────────┴───────────────┘
```
- 데스크톱 ≥1024: 3열(우측 패널은 기안·문서보기·메일 미리보기에서만). 768–1023: 우측 패널이 본문 아래로 이동. <768: 단일 열 + 하단 탭 바.
- CSS Grid: `grid-template-columns:220px minmax(0,1fr) 280px`. 본문 안 간격 16px, 카드 간 16px.

## 3. 내비게이션 트리
```
홈
결재
 ├ 결재대기 (n)   ├ 결재진행   ├ 결재완료   ├ 반려 (n)
 ├ 참조/열람 (n)  ├ 기안함     ├ 임시저장 (n) └ 부서문서함
 └ ✍ 기안하기
소통
 ├ 쪽지 (안읽음)  ├ 메일(향후)  ├ 게시판(공지 포함) └ 자료실
조직도

관리 (관리자만): 사원 / 부서 / 직위·서열 / 규정·전결 / 양식 / 감사로그 / 백업
```

현재 위치 항목은 `aria-current="page"` + 굵은 글씨 + 좌측 4px 바. 건수 배지는 0이면 숨김.

결재란 칸: 직위(상) / 이름 / 상태 도장(승인·반려·대기·전결·대결 텍스트 도장) / 날짜(하). 도장은 색 + 글자(색에만 의존 금지). 내 차례 칸은 굵은 테두리.

## 5. 컴포넌트

| 상태 칩 | 높이 24px, 라운드 12px, 굵은 12–13px 글. **어두운 글씨 + 옅은 배경 + 1px 테두리**, 앞에 기호(●✔✖) |
| 진행 | 배경 #FFE9A8 글 #4A3200 테두리 #D9A400 |
| 완료 | 배경 #C9EBCF 글 #0F3D1B 테두리 #3C9A55 |
| 반려 | 배경 #FAD0CC 글 #5C0F08 테두리 #C8402F |
| 대기/임시 | 배경 #E4E8EE 글 #1F2937 테두리 #8A94A6 |
| 지연 | 배경 #FFD3A6 글 #4A2000 |
| 버튼 primary | 배경 #1F4E9A 글 #FFF(대비 ≥7:1), 높이 40px(폰 44px) |
| 버튼 danger | 배경 #B3261E 글 #FFF, 반려·삭제 전용, 항상 확인 단계 |
| 버튼 secondary | 흰 배경 + 1px #8A94A6 + 글 #1F2937 |

## 7. 모바일 규칙
- <768px: 좌측 메뉴 제거, 하단 탭 바 5개 고정(높이 56px + safe-area): **홈 · 결재 · 기안 · 쪽지 · 더보기**. "더보기" = 게시판·자료실·조직도·설정·관리 목록 페이지(JS 없이 `/more` 링크 페이지 또는 `<details>`).
- 탭 터치 영역 ≥44×44px. 본문 하단에 탭 바 높이만큼 여백.
- 표 → 카드, 우측 패널 → 본문 내 접이식 카드, 문서 보기의 [결재][반려]는 하단 탭 바 위 고정 바.
- 폼 입력 16px 이상(iOS 확대 방지), `inputmode`/`autocomplete` 지정.
- 가로 스크롤 금지(`overflow-wrap:anywhere`, 첨부명 말줄임). `<meta name=viewport content="width=device-width,initial-scale=1">`.

## 8. 접근성
- 의미 있는 랜드마크: `header`, `nav aria-label="주 메뉴"`, `main`, `aside`. 본문 바로가기 링크("본문으로 건너뛰기") 첫 요소.
- 모든 정보는 색+글자/기호 병행. 텍스트 대비 ≥4.5:1(본 명세 색은 ≥7:1).
- 포커스 표시 3px 외곽선 항상 보임. 키보드만으로 모든 작업 가능, 확인 화면의 기본 포커스는 취소.
- 폼 `label for`, 오류는 필드 옆 문장 + `aria-describedby`, 전체 요약 `role=alert`.
- 표에 `<th scope>` 와 `<caption class=sr-only>`. 아이콘 단독 버튼은 `aria-label`.
- `prefers-reduced-motion` 존중(애니메이션 최소). 글꼴 확대 200%에서 레이아웃 유지(rem 단위).
- `lang="ko"`, 날짜는 `YYYY-MM-DD` 고정.
